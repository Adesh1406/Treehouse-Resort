# Treehouse-Resort
🌲 WILDWOOD — Treehouse Resort

A cinematic digital escape into the wild.

Wildwood is an immersive Treehouse Resort digital experience created for ACM Problem Statement 10 — Treehouse Resort.

Rather than behaving like a conventional resort website, Wildwood turns the browser into a cinematic journey through a living forest — combining immersive visuals, interactive environments, moving wildlife, luxury treehouse architecture, atmospheric motion and a minimal editorial interface.

🎬 Experience Preview



The Wildwood experience begins deep inside the forest, where the environment itself becomes the hero.

✨ The Vision

Don't just show the forest. Make the visitor feel like they're inside it.

Wildwood is designed around a continuous visual journey where the camera, environment, lighting, depth, animation and interaction become the storytelling tools.

The visitor gradually discovers:

🌲 A vast cinematic forest

🏡 Luxury treehouse architecture

🌉 Elevated paths and bridges

🌫️ Atmospheric mist and environmental depth

🦌 Living wildlife that moves through the environment

☀️ Natural lighting and atmosphere

🌌 Night-sky experiences

🛁 Resort experiences

🌿 Nature and sustainability

✨ A focused reservation experience

🦌 Living Wildlife

One of Wildwood's defining features is that the forest is not static.

Wildlife can appear and move through the environment, creating the feeling of a living ecosystem rather than a simple 3D background.

The interface also includes a wildlife spotting experience, allowing visitors to discover animals as they explore the forest.

The forest doesn't just look alive — it behaves like a living world.

🎥 The Experience

01 — Arrival

The journey begins deep inside the forest.

Towering trees, atmospheric depth, distant mountains, natural lighting and subtle environmental movement establish the feeling of entering a secluded luxury retreat.

02 — Discovery

The forest gradually opens and the resort begins to reveal itself through the trees.

The experience focuses on anticipation rather than showing everything immediately.

03 — Ascend

The camera travels upward through the forest, introducing the vertical character of the resort.

Elevated architecture, tree-level perspectives and bridges transform the forest into a destination.

04 — Sanctuary

Luxury treehouses become the focus.

Accommodation is presented as architecture integrated into nature rather than ordinary hotel cards.

05 — Living Experiences

The resort expands into a complete escape:

06 — Cinematic Gallery

A visual gallery presents the resort through a more editorial, film-inspired composition.

07 — Wildlife, Nature & Sustainability

🚀 Running Locally

Because the project uses JavaScript modules and Three.js resources, run it through an HTTP development server instead of opening index.html directly with file://.

VS Code + Live Server

Open the Wildwood folder in VS Code.

If VS Code shows Restricted Mode, trust the folder.

Install the Live Server extension.

Right-click index.html.

Select Open with Live Server.

Then open the local HTTP address generated by Live Server.

Important

Opening the HTML file directly can prevent module-based resources from working correctly.
